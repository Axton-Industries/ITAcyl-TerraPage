Gestión agrícola de precisión con visor geográfico

Terra centraliza el día a día de la explotación: parcelas SIGPAC, cultivos, registro de actuaciones y tratamientos, e imágenes multiespectrales georreferenciadas sobre un mismo visor. Software libre, instalable en escritorio o servidor local.

  • GeoTIFF multiespectral Carga, recorte y exportación

Funcionalidades

Una sola herramienta, todas las campañas

Diseñada para técnicos y productores que necesitan registrar lo que pasa en cada parcela y contrastarlo con la imagen que llega del dron o del satélite.

Visor geográfico

OpenLayers con mapas base (calles, Esri World Imagery, PNOA) y capa oficial SIGPAC servida por WMS.

Fichas de cultivo

Nombre, variedad, campaña, siembra, estado, observaciones y adjuntos. Parcela dibujada o importada de GeoPackage, GeoJSON o Shapefile.

Actuaciones y tratamientos

Registro de tareas agrícolas y productos fitosanitarios o fertilizantes, con adjuntos (fotos y documentos).

Imágenes multiespectrales

Carga de GeoTIFF, selección de banda y visualización georreferenciada sobre el mapa base.

Zonificación VRA

Estadísticas y umbrales automáticos para generar mapas de aplicación a tasa variable y exportarlos a Shapefile.

Recorte por parcelas

Recorta el ráster cargado a la unión de las parcelas seleccionadas para aligerar el procesado.

Cómo funciona

Tres pasos para pasar del campo al mapa

  1. 01

    Dibuja o importa tus parcelas

    Dibuja sobre SIGPAC, sube un GeoPackage/GeoJSON/Shapefile o deja que Terra empareje tu dibujo con los recintos oficiales.

  2. 02

    Carga la imagen del vuelo

    Sube un GeoTIFF multiespectral desde el navegador o desde el diálogo nativo de Electron. Elige banda y recorta por parcela.

  3. 03

    Registra y exporta

    Anota la actuación o tratamiento, adjunta fotos y exporta la zonificación VRA en Shapefile listo para tu maquinaria.

Tecnología

Una pila libre, lista para desplegar

Terra es software libre (GPL-3.0). Funciona como SPA en el navegador, con backend FastAPI y opcionalmente como aplicación de escritorio con Electron.

Frontend

  • React 19 + TypeScript
  • Vite
  • Tailwind CSS
  • Zustand (estado + persistencia)
  • OpenLayers + proj4

Backend

  • Python 3.12
  • FastAPI + Uvicorn
  • Pydantic
  • rasterio (ráster)

Distribución

  • Electron (escritorio)
  • electron-builder (NSIS)
  • PyInstaller (backend)

Descarga

Lleva Terra a tu explotación

Instala el instalador para Windows o clona el repositorio y arranca en local con npm run dev. La API REST está disponible en /api/docs.
